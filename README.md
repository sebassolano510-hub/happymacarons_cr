# Happy Macarons

Página web de Happy Macarons (@happymacarons_cr), publicada con GitHub Pages.

## Archivos
- `index.html`: contenido de la página.
- `style.css`: colores, letras y diseño.
- `script.js`: armador de cajas y pedido por WhatsApp.
- `img/`: logo, mascota y fotos.

## Cambios rápidos
- **Precios, sabores, número de WhatsApp o costo de entrega:** al inicio de `script.js`.
- **Textos de los sabores:** en `index.html`, sección "Nuestros sabores".
- **Colores:** al inicio de `style.css`.

Para agregar un sabor nuevo: suba la foto a `img/`, agréguelo a la lista `SABORES` en `script.js` y copie una tarjeta `<article class="flavor">` en `index.html`.
